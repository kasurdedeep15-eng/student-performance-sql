# Student Performance Management System

## 📌 Project Overview

A beginner-level SQL project built using MySQL to manage student information and analyze their academic performance.

## 🗃️ Database Structure

The project contains two tables:

### Students
- student_id
- name
- age
- gender
- city
- course

### Marks
- mark_id
- student_id
- subject
- marks

- GROUP BY

- JOIN
- Subqueries
- LIMIT

## 📊 Analysis

The project can be used to:

- Find students based on city or age
- Count students in each course
- Calculate average marks
- Find the highest marks
- Compare course performance
- Find top-performing students
